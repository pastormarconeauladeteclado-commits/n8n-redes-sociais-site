Política de Privacidade

Última atualização: 30 de setembro de 2026.

Esta Política de Privacidade explica como a aplicação n8n Redes Sociais trata dados necessários ao funcionamento das integrações com redes sociais.

1. Dados tratados

A aplicação pode tratar identificadores de conta, tokens de autorização, informações básicas do perfil autorizado, arquivos de mídia e metadados necessários para executar publicações solicitadas pelo usuário.

2. Finalidade

Os dados são usados exclusivamente para autenticar contas, executar automações, publicar conteúdos autorizados, verificar o resultado das publicações e manter o funcionamento técnico da aplicação.

3. Compartilhamento

Os dados são enviados apenas às plataformas e serviços necessários para executar as funções solicitadas pelo usuário. A aplicação não vende dados pessoais a terceiros.

4. Armazenamento e segurança

Credenciais e tokens são mantidos em ambiente controlado e usados somente para as integrações autorizadas. Medidas técnicas razoáveis são utilizadas para reduzir riscos de acesso não autorizado.

5. Revogação e exclusão

O usuário pode revogar as permissões diretamente nas plataformas conectadas. Também pode solicitar a exclusão de dados armazenados pela aplicação entrando em contato pelo e-mail informado abaixo.

6. Direitos do usuário

O usuário pode solicitar informações, correção ou exclusão de dados pessoais tratados pela aplicação, conforme aplicável.

7. Contato
